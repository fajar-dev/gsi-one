User Requirement Specification (URS)

Proyek: GSI One Mobile Application

1. Pendahuluan

Dokumen ini merangkum kebutuhan pengguna (user requirements) dari semua kelompok pemangku kepentingan yang akan menggunakan aplikasi GSI One. URS ini menjadi dasar pengembangan Software Requirement Specification (SRS) yang lebih terperinci.

2. Kebutuhan Pengguna: Klien / Customer

ID Kebutuhan Pengguna Prioritas
UR-01 Saya ingin dapat mendaftar akun menggunakan email dan kata sandi High
UR-02 Saya ingin dapat masuk ke aplikasi menggunakan akun yang sudah saya daftar High
UR-03 Saya ingin melihat daftar layanan teknik yang ditawarkan PT GSI High
UR-04 Saya ingin melihat detail dan studi kasus setiap jenis assessment Medium
UR-05 Saya ingin dapat memesan survei lapangan dengan mengisi form secara langsung High
UR-06 Saya ingin mendapatkan konfirmasi bahwa pesanan saya telah diterima High
UR-07 Saya ingin melihat status progres proyek saya secara real-time (fase 2) High
UR-08 Saya ingin dapat mengunduh laporan dan invoice proyek saya (fase 2) Medium

3. Kebutuhan Pengguna: Engineer GSI

ID Kebutuhan Pengguna Prioritas
UR-09 Saya ingin dapat memperbarui status tahapan proyek yang saya tangani High
UR-10 Saya ingin dapat menambahkan catatan harian pada setiap tahapan High
UR-11 Saya ingin dapat mengunggah foto, laporan, dan dokumen terkait proyek High

4. Kebutuhan Pengguna: Administrator / Marketing GSI

ID Kebutuhan Pengguna Prioritas
UR-12 Saya ingin dapat melihat semua proyek yang sedang berjalan High
UR-13 Saya ingin dapat membuat proyek baru dan menentukan tahapan timeline High
UR-14 Saya ingin dapat memantau keseluruhan progres semua proyek Medium
UR-15 Saya ingin dapat mengunduh semua dokumen yang terkait dengan proyek Medium
