Dokumentasi GSI One

Selamat datang di penampil dokumentasi interaktif untuk aplikasi mobile GSI One. Halaman ini dirancang untuk memudahkan developer, QA, dan stakeholder proyek dalam menjelajahi spesifikasi teknis dan non-teknis aplikasi secara offline.

Aplikasi GSI One adalah platform mobile berbasis React Native yang dikembangkan untuk PT Graha Survei Indonesia (GSI). Aplikasi ini membantu pengguna memantau kondisi kesehatan struktur secara real-time, mempelajari detail layanan teknik sipil GSI, serta mengajukan janji temu survei lapangan.

Rekomendasi Utama Pemilihan Infrastruktur:
* Untuk Kepatuhan Regulasi & Latensi Rendah (Server Lokal): Menggunakan Biznet Gio NEO Lite (Standard) adalah opsi terbaik (~Rp 469.000/bulan) karena data disimpan di Indonesia dan memiliki latensi minimal.
* **Untuk Efisiensi Biaya Terbesar (Global):** Menggunakan **VPS Hetzner** dengan skema multi-tenant memberikan spesifikasi tertinggi dengan harga termurah (~Rp 350.000/bulan).
* **Untuk Tanpa Maintenance Server:** Menggunakan **Supabase Cloud (Multi-Tenant)** dengan pemisahan database menggunakan PostgreSQL schema terpisah (~Rp 510.000/bulan).

Daftar Dokumen Utama

  • Software Requirements Specification (SRS): Merinci cakupan fungsional dan non-fungsional aplikasi menggunakan standar adaptasi IEEE 830.
  • Arsitektur Sistem & Alur Kerja SDLC: Menjelaskan daur hidup pengembangan sistem dan interaksi antara lapisan presentasi (React Native UI), state global (Zustand), penyimpanan sesi (AsyncStorage), dan RESTful API backend.
  • Spesifikasi Kontrak API: Menyediakan rincian endpoint login, register, dan booking beserta validasi isian formulir.
  • Project Tracking (Fase Berikutnya): Spesifikasi teknis fitur manajemen proyek berbasis timeline node, mencakup skema 5 tabel Supabase PostgreSQL, struktur penyimpanan file (Supabase Storage), peran pengguna, diagram ERD, dan alur penggunaan sistem.
  • Struktur Dokumentasi SDLC: Tabel lengkap 10 fase SDLC standar internasional ISO/IEC/IEEE beserta modul-modul panduannya.

Panduan Memulai Dokumentasi

Gunakan sidebar menu di sebelah kiri untuk menelusuri dokumentasi secara terstruktur berdasarkan fase pengembangan. Anda dapat:

  1. Memilih kategori folder untuk membuka daftar file dokumen di dalamnya.
  2. Memilih dokumen tertentu untuk memuat kontennya secara instan di panel pembaca ini.
  3. Beralih versi antara Versi HTML (untuk tampilan web berformat rapi) dan Versi Markdown (untuk melihat kode sumber dokumen).
  4. Membuka link dokumen secara terpisah di tab browser baru menggunakan tombol pintasan yang disediakan.
