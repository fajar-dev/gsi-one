## 2. Tujuan Proyek

Mengembangkan aplikasi mobile **GSI One** sebagai platform digital PT Graha Survei Indonesia untuk:
- Memperluas jangkauan layanan assessment struktur ke klien di seluruh Indonesia.
- Memberikan akses mudah kepada klien untuk memesan survey lapangan secara online.
- Membangun fondasi sistem manajemen proyek internal berbasis timeline (Project Tracking).

## 4. Ruang Lingkup (Scope)

### Dalam Ruang Lingkup
- Aplikasi mobile Android & iOS menggunakan React Native.
- Fitur autentikasi pengguna (login, register, logout).
- Fitur katalog layanan dan monitoring kesehatan struktur (SHMS).
- Fitur pemesanan survei lapangan (Book Survey).
- Fitur Project Tracking berbasis timeline node (fase berikutnya).

### Di Luar Ruang Lingkup
- Sistem ERP atau manajemen keuangan internal.
- Integrasi dengan platform pihak ketiga selain Supabase.
- Versi web application.

---

## 5. Deliverables

1. Source code aplikasi mobile (Android APK & iOS IPA).
2. Dokumentasi teknis lengkap (SRS, SDD, API Spec, Test Plan).
3. Layanan data Supabase dan Edge Function untuk operasi admin.
4. Panduan pengguna dan administrator.
